# AGENTS.md

The canonical repository work guidance for AI coding agents lives in
[`CLAUDE.md`](CLAUDE.md). Read it first — in particular the character-device
staging hazards and the SRD licence boundary, both of which will bite silently.

For rules-accuracy checks, content transcription, and playtest analysis on this
workstation, also read the machine-local
[SRD reference guide](.claude/srd-reference.local.md) when it exists. It routes
lookups into the local SRD 5.2.1 extraction; keep those machine-specific paths
out of published plugin surfaces.

This file exists so agent tools that look for `AGENTS.md` are routed to the same
single source of truth. Do not duplicate guidance here; edit `CLAUDE.md`
instead.
